# sizetest

構造が最小（ノード 1 個）で、サイズだけ大きい ONNX。

laya-bot-det が WebKit で `InferenceSession.create` の中でタブごと落ちる原因が、
**バイト数**なのか**グラフの複雑さ**なのかを分けるために作った。Laya は数千ノード、
これは 1 ノードなので、サイズだけを変数にできる。

| ファイル | サイズ | ノード数 |
|---|---|---|
| `size32.onnx` | 34 MB | 1 |
| `size325.onnx` (5 分割) | 341 MB | 1 |

341 MB が通れば、原因はサイズではなくグラフ側にある。
